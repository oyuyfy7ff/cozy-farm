# ฟาร์มสุขใจ (Cozy Farm)

เกมฟาร์มไอโซเมตริกสไตล์การ์ตูนสีสด สร้างด้วย **Godot 4.3** (ภาพทุกอย่างวาดด้วยโค้ด ไม่มีไฟล์ภาพ)

## วิธีเล่น
- เลือกเครื่องมือด้านล่าง: **ไถดิน / ปลูก / รดน้ำ / เก็บเกี่ยว** แล้วแตะหรือลากนิ้วบนแปลง
- เลือกเมล็ดพันธุ์ (ซื้อทันทีตอนปลูก) — แปลงที่รดน้ำแล้วโตเร็วกว่า 4 เท่า
- เก็บผลผลิตเข้าคลัง แล้วขายให้ **ผู้ซื้อ** ทางขวา:
  - เด็กน้อย (ราคา x1.15), แม่ครัว (x1.3), พ่อค้าคนกลาง (x0.9 แต่ซื้อเยอะ), เศรษฐี (x2.2 แต่ใจร้อน)
  - ผู้ซื้อมีความอดทนจำกัด ถ้าไม่ขายให้ทันเขาจะเดินจากไป
- **ตลาดกลาง** รับซื้อทุกอย่างที่ 70% ของราคา — ราคาตลาดเปลี่ยนทุกวัน (1 วัน = 60 วินาที)
- **ร้านอัปเกรด**: ขยายที่ดิน, ปุ๋ยเร่งโต, บัวรดน้ำใหญ่
- เซฟอัตโนมัติ

## ฟอนต์ภาษาไทย
GitHub Actions จะโหลด Sarabun ให้เองตอน build ถ้าจะรันใน Godot editor ให้วางไฟล์
`fonts/Sarabun-Bold.ttf` (จาก Google Fonts) ไว้ในโฟลเดอร์ `fonts/`

## GitHub Actions
Push ขึ้น `main` แล้ว workflow `Build Cozy Farm` จะ:
1. Export **Web** → deploy ขึ้น GitHub Pages (ตั้ง Settings → Pages → Source = **GitHub Actions**)
2. Export **Android APK** (เซ็น debug) → โหลดได้ที่ Actions → Artifacts → `cozy-farm-apk`
